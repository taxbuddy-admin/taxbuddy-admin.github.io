# TaxBuddy Partner API Docs

Welcome to the TaxBuddy developer portal. This documentation covers the APIs available to authorised integration partners.

---

## Base URLs

| Environment | Base URL |
|-------------|----------|
| UAT | `https://uat-api.taxbuddy.com` |
| Production | `https://api.taxbuddy.com` |

---

## Authentication

All APIs require an API key passed as a request header:

```bash
x-api-key: YOUR_API_KEY
```

API keys are issued by the TaxBuddy team during partner onboarding. Contact [ashwini@taxbuddy.com](mailto:ashwini@taxbuddy.com) to request access.

---

## Available APIs

| Category | APIs |
|----------|------|
| **Calculators** | Pension, NPS, NPS V1, EPF, EPF V1, Form 12BB, Old vs New Regime |
